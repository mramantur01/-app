# KG Taxi — безопасность и настройка

## Роли (водитель, диспетчер)

Сам себе роль выдать нельзя: правила Firestore запрещают запись в коллекцию `roles` из приложения.
Роль выдаёт владелец в консоли Firebase:

1. Firebase Console → Firestore Database → коллекция `roles`.
2. Документ с ID = UID пользователя (Authentication → Users).
3. Поле `role` (string): `driver`, `dispatcher` или `admin`.
4. Для водителя также (все — string):
   - `car` — марка, модель и цвет, например `Toyota Camry 70, белый`;
   - `plate` — госномер, например `01KG 123 ABC`;
   - `payPhone` — номер для перевода MBank / O!Деньги (необязательно). Пассажир увидит его в поездке.

Эти данные пассажир видит, когда водитель принимает заказ.

Пользователь увидит новый режим после повторного входа в аккаунт.

## SOS

Кнопка SOS:
- открывает набор **112** (пользователь сам нажимает «позвонить» — случайного вызова не будет);
- готовит SMS с геопозицией для доверенных контактов (раздел «Семья» в профиле);
- записывает тревогу в `sos_alerts` — её видят диспетчеры.

Если человек не вошёл в аккаунт или нет интернета, диспетчер тревогу не получит, но звонок и SMS работают.

## Платёжные ключи

Всё, что лежит в `.env`, попадает внутрь APK, а APK может распаковать кто угодно.
Поэтому `PAYMENT_GATEWAY_WEBHOOK_URL` и `PAYMENT_GATEWAY_API_KEY` **запрещены** в `.env`
(они в `ignoreList` в `app/build.gradle.kts`). Выплаты владельцу из приложения не отправляются —
только записываются как заявка.

Для настоящих выплат нужна серверная функция (Firebase Cloud Functions), где ключ хранится как секрет:

```
firebase functions:secrets:set PAYMENT_GATEWAY_API_KEY
```

## Что выключено до запуска

См. `app/src/main/java/com/example/FeatureFlags.kt`. Сейчас включены только такси по городу и
межгород, оплата наличными. Кошелёк, онлайн-оплата, еда, курьер, грузовые, почасовая аренда,
ИИ-помощник, голосовые команды и абонементы водителей скрыты. Чтобы вернуть функцию — поставьте её флаг в `true`.

## Сборка в GitHub

Файл `.github/workflows/android-build.yml` собирает APK при каждом push.
Готовый APK: вкладка **Actions** → последний запуск → **Artifacts** → `kg-taxi-debug-apk`.

Чтобы работали вход и база, добавьте секрет репозитория `GOOGLE_SERVICES_JSON`
(Settings → Secrets and variables → Actions) с содержимым `google-services.json` из консоли Firebase.

## Заявки водителей

Пассажир, который нажимает вкладку «Водитель» без роли, заполняет анкету. Она сохраняется в
коллекции `driver_applications` (документ = UID). Чтобы одобрить:

1. Проверьте документы человека (права, техпаспорт) лично или по мессенджеру.
2. Создайте `roles/{UID}` с полями `role: "driver"`, `car`, `plate`, `payPhone` (возьмите из анкеты).
3. В анкете поменяйте `status` на `approved` (или `rejected`).

## Push-уведомления (нужен тариф Blaze)

Код сервера — в папке `functions/`. Он присылает:
- водителям на линии в этом городе — «Новый заказ»;
- пассажиру — «Водитель едет», «Машина подъехала», «Поездка завершена», «Заказ отменён»;
- обеим сторонам — новые сообщения чата.

Как включить:
1. Firebase Console → Upgrade → тариф **Blaze** (нужна карта; на старте расходы почти нулевые).
2. На компьютере: `npm install -g firebase-tools`, `firebase login`, затем в папке проекта
   `cd functions && npm install && cd .. && firebase deploy --only functions --project gen-lang-client-0409944414`.

Приложение уже сохраняет push-токен каждого телефона в `device_tokens/{UID}`.
